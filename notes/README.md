# Notes

One Markdown file per topic or source, named `<topic-slug>.md` (for example `llm-agents-soc-triage.md`).

Each note should:

- Start with the question it answers and the date it was written.
- Cite every claim inline with a DOI, arXiv ID, or venue and year.
- End with a `## Sources` list of everything cited.
- Keep what a source says separate from our own interpretation, for example under a `## Takeaways` heading.

Tickets in `.scratch/topic-search/issues/` link to the notes they rely on.
